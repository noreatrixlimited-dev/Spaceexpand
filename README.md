# Space Expand

*Paint. Steal. Betray.*

A cute, toy-like 3D browser game for 4 players. Each player starts in one corner of the board with a pet **Core** (an egg in a nest). Paint trails to expand your land, protect your Core, and steal everyone else's.

- Plan and game design: [`docs/PLAN.md`](docs/PLAN.md)
- Status: planning (no code yet)

## Tech (planned)
